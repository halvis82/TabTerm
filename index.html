TabTerm

A macOS terminal where sessions behave like native Chrome tabs.

The tabs are the interface. The terminals are real processes on your Mac, owned by a small companion program that keeps them alive when Chrome is not looking at them. Closing a tab does not end your work, and a browser restart does not either.

Requirements

  • macOS 13 or newer
  • Chrome 120 or newer
  • Node 22 or newer, and zsh

Install

git clone https://github.com/halvis82/TabTerm.git
cd TabTerm
npm install && npm run build
./scripts/install.sh

Then load the extension, or install it from the Chrome Web Store. Full instructions are in the README, and ./scripts/doctor.sh checks every part of the setup and says which one is unhappy.

Privacy

There is no TabTerm server. Nothing is uploaded, because there is nowhere to upload it to. The privacy policy says exactly what is handled and what is written to your disk.
